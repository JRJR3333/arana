# Hito h4 · La araña como widget

**Qué consigue:** la araña en su pantalla de inicio o de bloqueo. Le saluda, le recuerda la rutina que suele hacer a esta hora y, con un toque, abre la araña con esa rutina ya pedida.

**Tiempo:** unos 8 minutos, desde el iPhone. Hace falta la app gratuita **Scriptable** (App Store). El atajo **Araña** no se toca.

## 1. Instalar el script

1. Instale **Scriptable** desde la App Store.
2. Abra en Safari este enlace y copie todo el texto:
   https://raw.githubusercontent.com/JRJR3333/arana/master/nativo/scriptable/arana-widget.js
3. En Scriptable pulse **+**, pegue el texto y ponga de nombre **Araña** (arriba). Pulse **OK**.
4. Pulse ▶︎ para probarlo: verá la araña en una vista previa.

## 2. Copiar los datos de la araña

1. Abra la araña → **Evolución** → **Widget · con la app Scriptable**.
2. Pulse **Copiar datos del widget**. Copia su nombre y sus rutinas con hora; nada más.

Si aún no tiene rutinas con hora, el widget funciona igual: solo saluda. Vuelva a copiar los datos cuando la araña aprenda rutinas nuevas.

## 3. Poner el widget

**En la pantalla de inicio:**

1. Mantenga pulsado un hueco → **Editar** → **Añadir widget** → **Scriptable** → tamaño pequeño o mediano → **Añadir widget**.
2. Toque el widget (aún en modo edición) para configurarlo:
   - **Script:** Araña
   - **When Interacting:** déjelo como esté; el widget ya sabe qué abrir.
   - **Parameter:** pegue los datos copiados.
3. Toque fuera para terminar.

**En la pantalla de bloqueo:** mantenga pulsada la pantalla bloqueada → **Personalizar** → **Pantalla bloqueada** → toque la fila de widgets → **Scriptable** (redondo o rectangular) → configure igual que arriba.

## 4. Comprobar

- A la hora de una de sus rutinas, el widget dice «A esta hora suele …».
- Al tocarlo se abre la araña y hace la rutina.
- Si funciona, vaya a la araña → **Evolución** → **Ya funciona** en el hito h4.

## Si algo falla

- **«Datos del widget no válidos»:** vuelva a copiar los datos y péguelos enteros en *Parameter*.
- **No se actualiza:** iOS refresca los widgets cada cierto tiempo (unos 15–30 minutos). No es inmediato.
