# Hito h4 · La araña en su pantalla de inicio, sin instalar nada

**Qué consigue:** un widget con teclas de la araña: una para hablarle («Araña voz») y una por cada rutina suya. Un toque y se hace.

**Tiempo:** unos 6 minutos, desde el iPhone. Solo usa la app **Atajos**, que ya viene en el iPhone. El atajo **Araña** no se toca.

## 1. Crear la carpeta

1. Abra **Atajos** → pestaña **Atajos** → arriba a la izquierda, **‹ Atajos** → icono de carpeta con **+**.
2. Póngale de nombre **Araña** y pulse **Añadir**.
3. Mueva ahí su atajo **Araña voz** (hito h2): manténgalo pulsado → **Mover** → **Araña**.

## 2. Una tecla por rutina

1. Abra la araña → **Evolución** → **Recetario de rutinas**.
2. Pulse **Copiar texto del atajo** (si sale) o **Copiar enlace**.
3. En Atajos, dentro de la carpeta **Araña**, pulse **+** y añada una acción:
   - Con el **texto del atajo**: **Ejecutar atajo** → elija **Araña** → toque *Entrada* → **Texto** y pegue. Funciona sin abrir Safari.
   - Con el **enlace**: **Abrir URL** y pegue. El enlace ya lleva los pasos de la rutina, así que funciona aunque Safari no tenga la memoria del icono.
4. Arriba, póngale el nombre de la rutina (por ejemplo **Modo cine**) y, si quiere, un icono y un color.
5. Repita con cada rutina que quiera tener a mano.

## 3. Poner el widget

1. En la pantalla de inicio, mantenga pulsado un hueco → **Editar** → **Añadir widget** → **Atajos**.
2. Elija el tamaño (el mediano muestra 4 teclas; el grande, 8) → **Añadir widget**.
3. Toque el widget (aún en modo edición) → **Carpeta** → **Araña**.
4. Toque fuera para terminar.

**En la pantalla de bloqueo (iOS 18):** mantenga pulsada la pantalla bloqueada → **Personalizar** → **Pantalla bloqueada** → toque el botón de abajo (linterna o cámara) → **–** → **+** → **Atajo** → **Araña voz**.

## 4. Comprobar

- Toque **Araña voz** en el widget y diga una orden.
- Toque una rutina: debe hacerse sola.
- Si funciona, vaya a la araña → **Evolución** → **Ya funciona** en el hito h4.

## Si algo falla

- **No aparece «Copiar texto del atajo»:** la rutina abre apps; use **Copiar enlace**.
- **Pide permiso la primera vez:** es normal. Pulse **Permitir siempre**.
